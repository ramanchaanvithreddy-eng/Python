Student Marks Calculator
 Description
A beginner Python program that takes a student's name and marks in three subjects and calculates the total and average.
Concepts Learned
- Variables
  input()
  `print()
- Data types
- Type conversion using float()
- Arithmetic operators

 How It Works

1. Takes the student's name.
2. Takes marks for Python, Maths, and ML.
3. Calculates the total marks.
4. Calculates the average.
5. Displays the result.

Example
 Input
text
Enter student name: Anvith
Enter Python marks: 85
Enter Maths marks: 90
Enter ML marks: 80
